# java-calculator-precourse

### 사용자 입력 및 출력

- 프로그램 시작 시 “덧셈할 문자열을 입력해 주세요.” 출력
- 한 줄 입력을 받는다. null 또는 공백만 입력 시 `결과 : 0` 출력 후 종료.
- 해당 문자열에서 구분자를 기준으로 숫자 추출하여 계산 수행
- 정상 계산 시 `결과 : <합계>` 형식으로 출력한다.
- `""` → 빈 문자열일 경우는 0

### 구분자 종류

- 기본 구분자는 쉼표(,) 와 콜론(:)
- 커스텀 구분자는 “//”와 “\n” 사이에 위치하게끔 해서 만들기
    - 커스텀 구분자를 지정한 경우, 기본 구분자는 동작하지 않는 것인가? → 커스텀 지정 시 해당 문자만 사용
    - 커스텀 구분자는 2자 이상도 허용
    - 커스텀 구분자는 유니코드 허용
    - 정규식에서 사용되는 특수문자(*, |, ?, ., +, [, ], \ 등)도 일반 문자 구분자와 동일하게 인식해야 한다.
- 커스텀 구분자 지정 시, 기본 구분자는 사용하지 못한다.

### 숫자의 범위

- 각 숫자와 총합의 자료형은 int로 한다.
    - 합계가 Integer.MAX_VALUE를 초과하면 예외.
- 숫자 이외의 문자가 들어올 시 예외 (ex. 1,a,3)
- 음수는 금지

### 예외 처리 (모든 사용자 입력 오류는 즉시 종료)

- 사용자의 입력 오류일 경우에는 `IllegalArgumentException` 발생시킴
    - `,2,3` 빈 값 토큰: [400 error] 빈 값은 허용되지 않습니다.
    - `-1,2,3` → [400 error] 숫자는 양수여야 합니다.
    - `1,2;3` → [400 error] 정의되지 않은 구분자가 포함되었습니다.
    - `,1,2` → [400 error] 빈 값은 허용되지 않습니다… 등등
